# Environment files — shared vs secrets (DRY compose)

How multi-app clusters layer env so **compose stays dry**, **non-secrets stay in
git**, **shared secrets** and **per-app secrets** stay out of git, and **`.env`
is left for you** (we do not overwrite it).

Package-manager **cache paths** (`BUNDLE_PATH`, `YARN_*`, …) come from the
**ubuntu-mise** image — not from these files. See
[ubuntu-mise runtime-env-not-required](https://github.com/Ruby-on-Rails-Wizardry/ubuntu-mise/blob/master/docs/runtime-env-not-required.md).

## Inventory

| File | Role | In git? | Who writes |
|------|------|---------|------------|
| **`config/shared.env`** | Shared **non-secrets** for every app (`RAILS_ENV`, flags, …) | **Yes** | You |
| **`.common.env`** | Shared **secrets** for every app (API keys, proxy secrets, …) | **No** | Vault / you |
| **`.<app>.env`** | Per-app secrets (e.g. `.fred.env`) | **No** | Vault / you |
| **`config/compose.env`** | Compose **interpolation** only (`IMAGE`, `WORK_MOUNT`, `POSTGRES_*` defaults) | **No** | `bin/compose` |
| **`.env`** | **Yours** — we do **not** overwrite | Your choice | You |
| **`.mise.env`** | Host tool defaults | Yes | You |
| **`compose.yml` `environment:`** | Topology (ports, `DATABASE_URL` hostnames) | Yes | You |

## Target model

```text
config/shared.env     # committed non-secrets → x-app env_file
.common.env           # shared secrets (vault) → compose.secrets.yml
.fred.env             # per-app secrets (vault) → compose.secrets.yml
config/compose.env    # generated by bin/compose for ${IMAGE} substitution only
# .env                # left alone
```

```yaml
# compose.yml — x-app
env_file:
  - config/shared.env
```

```yaml
# compose.secrets.yml — generated (bin/env-files write)
services:
  fred:
    env_file:
      - .common.env
      - .fred.env
```

```bash
bin/compose up fred   # uses config/compose.env for interpolation + secrets fragment
```

## Manifest: `config/env.yml`

```yaml
shared:
  - config/shared.env

shared_secrets:
  - .common.env

app_secrets: {}
# default per app: .<name>.env

options:
  require_secrets: false
  secrets_compose: compose.secrets.yml
```

## Commands

```bash
task env:files -- status
task env:files -- write
bin/compose up …
```

## Rules

1. **Non-secrets** → `config/shared.env` (committed).
2. **Shared secrets** → `.common.env` (gitignored; vault).
3. **Per-app secrets** → `.<app>.env` (gitignored; vault).
4. **Do not** put secrets in `config/shared.env`.
5. **Do not** rely on us managing `.env` — use `config/compose.env` for compose knobs.
6. Topology stays in compose `environment:`.
7. Do not re-inject package-cache `BUNDLE_*` / `YARN_*` / … for default ubuntu-mise.
